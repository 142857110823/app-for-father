# calendar-core — 公共历法核心

> 版本：v1.0.0（2026-08-24 冻结）
> 上级：`features/README.md`、`其他功能——总规划.md`

## 1. 范围

提供四项其他功能（bazi、ziwei、meihua、daliuren）统一调用的历法能力：

- 公历 ↔ 农历转换
- 节气定位（节令、中气）
- 干支计算（年柱、月柱、日柱、时柱）
- 时区标准化
- 真太阳时修正（可选，默认关闭）
- 子时边界（默认 23:00 子初换日；可选 00:00 换日）

## 2. 默认规则

| 项目 | 默认 |
|---|---|
| 子时换日 | 子初 23:00 |
| 年柱分界 | 立春 |
| 月柱分界 | 节令 |
| 时区 | 用户所在地时区（默认 Asia/Shanghai） |
| 真太阳时 | 可选，默认关闭 |
| 闰月 | 输入层保留闰月标志，干支按节气 |

## 3. 接口

详见 `engine/calendar.js` 导出。

## 4. 依赖

- `lunar-javascript` ^1.6.11（项目现有依赖，固定版本）
- 仅通过 `calendar-core` 暴露给其他功能，禁止其他功能直接 require `lunar-javascript`

## 5. 已知争议

- 真太阳时计算需经度；缺经度时退回时区时间，并标记 `trueSolarTimeApplied: false`。
- 子初换日存在早晚子时之争；本核心默认 23:00 即换日，但保留 00:00 选项。

## 6. 测试边界

- 立春前后 2 分钟
- 每个节令交界前后
- 22:59、23:00、23:59、00:00
- 闰月、公历闰日、跨时区、夏令时历史日期
- 真太阳时跨时辰边界
