# 梅花易数功能规划

> 状态：仅规划。未来作为“我的 → 其他”第三项。

## 1. 第一版边界

支持时间起卦和两数起卦，输出本卦、互卦、变卦、动爻、体卦、用卦、五行生克与基础结构说明。第一版不自动断具体事件，不把算法输出包装为确定性预言。

## 2. 推荐规则

### 时间起卦

默认采用农历年月日时数起卦，并明确记录：

- 年支数。
- 农历月数、日数。
- 时支数。
- 上卦、下卦和动爻所用求和式。
- 余数为 0 时按 8 或 6 处理。

### 数字起卦

- 输入两个正整数。
- 第一数定上卦，第二数定下卦。
- 两数之和定动爻。
- 所有取余过程写入推演记录。

不同版本公式不得在同一结果中混用；通过 `ruleset` 明确区分。

## 3. 核心数据

- 八卦序数、先天卦序、五行、方位、象类。
- 六十四卦上下卦组合。
- 互卦取爻规则。
- 动爻变卦规则。
- 体用判定规则。
- 五行生克、比和关系。

## 4. 算法流水线

```text
输入
→ 数值标准化
→ 上下卦取余
→ 本卦
→ 动爻
→ 体用
→ 互卦
→ 变卦
→ 五行关系
→ 结构化说明
```

## 6. 页面

- 顶部分段控件：“时间起卦 / 数字起卦”。
- 卦象使用稳定六爻图，不因动爻标识改变布局。
- 本卦、互卦、变卦横向对比；小屏改为纵向。
- “推演过程”逐式展示，不只给最终卦名。
- “结构分析”分体用、生克、动静三段，不直接输出吉凶承诺。

## 7. 测试

- 所有余数 0 边界。
- 八卦上卦和下卦全覆盖。
- 六个动爻全覆盖。
- 互卦取爻与变爻位测试。
- 时间起卦跨子时、跨农历月、跨年。
- 两数相同、极大整数、非法输入。
- 至少 30 个带算式的标准案例。

## 8. 资料策略

- 一级依据为公版《梅花易数》原文中的起卦、体用、互变规则。
- 现代网页示例仅用于发现测试案例，必须回到原文或已冻结规则核对。
- 候选文本：`https://zh.wikisource.org/wiki/梅花易數`

## 9. 未决事项

- 时间起卦是否采用农历年支数或公历年份数。
- 分钟是否参与现代时间起卦。
- 体卦判定对动爻上下卦的具体口径。
- 卦辞、爻辞是否内置；推荐后置到“学堂/知识说明”，不与排盘算法耦合。
