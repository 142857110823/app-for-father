# 大六壬功能规划

> 状态：仅规划。未来作为“我的 → 其他”第四项。

## 1. 第一版边界

第一版必须形成完整基础课体：月将、天地盘、四课、三传和十二天将。只做“天地盘”或只列三传不算完整功能。课体、神煞和断语可分阶段增加，但取三传的核心规则不能长期占位。

## 2. 推荐规则范围

- 以占时、节气/月将和日干支为核心输入。
- 月将加占时布地盘。
- 建立天盘十二支映射。
- 依日干支、寄宫规则取四课。
- 按九宗门/取传规则判定三传。
- 贵人起法与十二天将顺逆布列。
- 输出伏吟、反吟、涉害等命中规则及证据。

第一版规则包必须明确采用的寄宫、贵人昼夜、月将交接和涉害深浅口径。

## 3. 输入

- 起课公历日期时间、时区、地点。
- 可选真太阳时，默认关闭。
- 昼夜判定规则。
- 月将交接规则。
- 可选问事类别和备注，不参与基础排盘。

## 4. 算法流水线

```text
时间标准化
→ 节气与月将
→ 占时地支
→ 月将加时布天地盘
→ 日干寄宫
→ 四课
→ 三传候选
→ 九宗门决策树
→ 初中末传
→ 贵人
→ 十二天将
→ 课体与推演证据
```

三传算法必须返回决策轨迹，例如：

```js
{
  candidates,
  ruleChecks: [
    { rule: "贼克", matched: false },
    { rule: "比用", matched: false },
    { rule: "涉害", matched: true, evidence: [] }
  ],
  transmissions: { initial, middle, final }
}
```

## 6. 页面

- 输入页突出起课时间和规则设置。
- 主盘先显示天地盘环形/方形结构，再显示四课三传。
- 三传使用“初传 → 中传 → 末传”的清晰链路。
- 天将和地支使用不同视觉层级，不依赖颜色区分。
- 提供“取传过程”页，逐项展示命中的九宗门规则。

## 7. 测试

- 十二占时、十二月将组合覆盖。
- 六十日干支覆盖。
- 昼贵/夜贵切换。
- 顺布/逆布天将。
- 贼克、比用、涉害、遥克、昴星、别责、八专、伏吟、反吟等分支。
- 四课重复、无克、多克等冲突情况。
- 至少 50 个标准课，三传复杂度高于其他三个功能。

## 8. 资料策略

- 一级依据为《六壬大全》等公版典籍。
- 先将规则整理为可执行决策表，再写代码；禁止直接从口诀跳到大量条件分支。
- 任何开源实现只用于交叉核验，并审查许可证与规则口径。
- 候选文本：`https://zh.wikisource.org/wiki/六壬大全_(四庫全書本)`

## 9. 主要风险

- 同名规则在不同传承中细节不一致。
- 涉害深浅、孟仲季、日干寄宫等实现容易出现隐性分支。
- 只核对最终三传无法定位错误，必须保存四课与每一步候选。
- 规则量大，不适合与现有奇门算法写在同一文件。

## 10. 未决事项

- 月将交接按中气的精确时刻还是日期。
- 贵人昼夜分界。
- 日干寄宫表版本。
- 九宗门优先级和涉害细则。
- 第一版课体标签范围。

推荐：大六壬在四个功能中最后开发，并单独进行规则评审。

## 11. 禁止实施

本轮不得新增大六壬入口、盘面、规则表或算法代码。
