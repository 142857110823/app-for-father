# 紫微斗数功能规划

> 状态：仅规划。原“智能罗盘”在未来实施阶段替换为本功能。

## 1. 第一版边界

输出十二宫命盘、命宫/身宫、五行局、主星与基础辅星、四化、大限和流年。第一版不做全流派混合、飞宫四化全集、自动事件预测和 AI 代替排盘。

## 2. 推荐流派范围

采用“基础三合盘”作为第一版固定口径：

- 十二宫、命身宫、五行局。
- 十四主星及明确列入规则表的常用辅煞星。
- 生年四化。
- 大限与流年。
- 庙旺平陷必须绑定明确表格版本。

飞星、钦天、河洛等差异较大的扩展体系后置为独立规则包，禁止混算。

## 3. 输入

- 性别、出生公历/农历年月日时。
- 闰月标志、时区、出生地、真太阳时开关。
- 子时换日、闰月处理规则。
- 可选姓名，仅用于记录，不参与算法。

## 4. 算法流水线

```text
历法标准化
→ 农历月日与时辰
→ 命宫/身宫
→ 十二宫宫职
→ 五行局
→ 紫微星定位
→ 十四主星安置
→ 辅星/煞星安置
→ 生年四化
→ 大限
→ 流年
```

每一颗星都必须输出 `ruleId`、原始输入和落宫推导，不允许只保存最终十二宫数组。

## 5. 数据结构

```js
{
  lunarDate,
  soulPalace,
  bodyPalace,
  fiveElementClass,
  palaces: [{
    earthlyBranch,
    role,
    heavenlyStem,
    majorStars: [],
    minorStars: [],
    transformations: []
  }],
  decadal: [],
  yearly: [],
  ruleset
}
```

## 6. 页面

- 输入页保持移动端单列。
- 命盘使用 4×4 十二宫表，中间区域显示基本资料和当前限运。
- 顶部用分段控件切换“本命 / 大限 / 流年”。
- 点击宫位进入宫位详情；星曜说明与盘面分离。
- 星曜密度过高时使用分组和展开，不缩小到不可读字号。

## 7. 测试

- 十二时辰全覆盖。
- 闰月前月/闰月/后月。
- 子时换日前后。
- 阴阳男女四组合的大限顺逆。
- 五行局各类型。
- 紫微星十二宫定位覆盖。
- 十四主星完整性与唯一性约束。
- 至少 30 个外部标准盘，逐宫比对。

## 8. 资料与实现候选

- `iztro` 可作为成熟开源实现的交叉核验候选，不直接成为唯一真值。
- 必须冻结版本、许可证、参数，并将采用的安星口诀和表格转写为项目规则文档。
- 候选资料：`https://github.com/SylarLong/iztro`、`https://iztro.com/`

## 9. 未决事项

- 闰月按前月、后月或分日处理。
- 晚子时是否换日。
- 第一版辅煞星清单。
- 四化表采用哪一版本。
- 大限起岁和虚实岁显示方式。

推荐：开发前先单独做“紫微规则确认书”，用户批准后冻结 `ruleset-v1`。

## 10. 禁止实施

本轮不得修改“智能罗盘”入口，不得引入 `iztro` 依赖，不得生成紫微页面。
