# 四柱八字功能规划

> 状态：仅规划。原“万年历”在未来实施阶段替换为本功能。

## 1. 第一版边界

提供公历/农历出生信息输入，输出年柱、月柱、日柱、时柱、藏干、十神、五行统计、旺衰辅助信息、起运信息、大运和流年列表。不提供自动婚姻、疾病、寿命、灾祸等确定性断语。

## 2. 推荐规则

| 项目 | 推荐默认 |
|---|---|
| 年柱分界 | 立春 |
| 月柱分界 | 节令，不按农历初一 |
| 日界 | 子初 23:00，可切换 00:00 |
| 时柱 | 12 时辰，保留早晚子时信息 |
| 时区 | 用户所在地时区 |
| 真太阳时 | 可选，默认关闭 |
| 闰月 | 输入层保留闰月标志，四柱仍按节气 |
| 大运顺逆 | 按固定流派参数计算，规则必须在设置中可见 |
| 起运岁数 | 精确到年/月，保留原始时间差 |

## 3. 输入

- 姓名可选、性别、出生日期时间。
- 公历/农历模式、闰月标志、时区、城市/经纬度。
- 子时换日规则、真太阳时开关、未知时辰模式。

未知时辰只能输出年/月/日三柱，并明确标记所有受时柱影响的字段不可用。

## 4. 算法流水线

```text
输入校验
→ 时区标准化
→ 可选真太阳时修正
→ 节气定位
→ 年/月/日/时柱
→ 藏干
→ 日主十神
→ 五行与阴阳统计
→ 起运方向与起运时间
→ 大运
→ 流年
```

五行“强弱”第一版只给出可审计的计数、月令、通根、透干和生克关系，不把未经用户确认的综合打分公式包装成传统定论。

## 5. 数据结构

```js
{
  pillars: { year, month, day, hour },

  startLuck: { direction, age, date, evidence },

  options: { dayBoundary, trueSolarTime, timezone }

```

## 6. 页面

- 输入页：日期模式、时间地点、规则设置。
- 命盘页：四柱主表、藏干、十神。
- 五行页：数量与关系，不使用夸张雷达图。
- 运势页：大运时间轴、流年切换。
- 推演过程：展示节气、换日、起运差值。

## 7. 测试

- 立春前后各 2 分钟。
- 每个节令交界前后。
- 22:59、23:00、23:59、00:00。
- 闰月、公历闰日、跨时区、夏令时历史日期。
- 真太阳时跨时辰边界。
- 未知时辰。
- 至少 30 个带中间步骤的标准案例。

## 8. 资料与实现候选

- 规则说明必须落为项目文档，不能只引用第三方库输出。
- 候选资料：`https://github.com/6tail/lunar-javascript`

## 9. 未决事项

- 大运顺逆采用哪一套性别/年干阴阳规则。
- 起运按三天一年折算时，时分精度和取整方式。
- 是否显示神煞；推荐第一版不显示，待单独建立规则表后再加入。
