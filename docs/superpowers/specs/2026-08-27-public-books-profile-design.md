# 公开访问 + 书院阅读 + 我的页面优化 设计文档

> 设计日期：2026-08-27
> 对应需求：①【精选书籍】可正常阅读电子版；②提供外网可访问的公开网址；③【我的】页面视觉优化。

---

## 一、目标与成功标准

1. 普通用户在任何设备打开公开链接后，无需本地服务器即可正常阅读书院中的电子书。
2. 项目部署到一个长期可用的公开网址（优先免费方案）。
3. 【我的】页面从单调列表升级为有层次、有品牌氛围的个人中心。

---

## 二、方案概述

### 2.1 部署方案：Render 免费 Web Service

- **选择理由**：当前工程已经是 Express 后端（`server.js`），Render 可直接运行 Node.js，无需改造架构。GitHub Pages 仅支持静态页，会导致 AI 对话、短信登录、书籍下载全部失效。
- **目标域名**：`https://qimen-13gong.onrender.com`（示例，以实际创建为准）。
- **部署方式**：GitHub 仓库 → Render Web Service → 自动部署。
- **环境变量**：`PORT=8090`（Render 自动注入），`AI_API_KEY` 从 `API密钥.txt` 读取。

### 2.2 书院阅读改造：在线阅读 + 离线阅读双模式

#### 当前问题
- 当前 EPUB 必须先下载到 IndexedDB 才能阅读，在隐私模式、陌生设备或静态部署下容易失败。
- 下载 URL 构建逻辑复杂，优先本地、其次远程，容易指向不可用的地址。

#### 改造后逻辑
1. 每本书卡片显示两个操作按钮：
   - **阅读**：直接通过 epub.js 读取服务器 `/books/{id}.epub`，无需先下载。
   - **下载离线**：保留现有下载逻辑，下载后 IndexedDB 中可离线阅读。
2. 阅读器统一使用 URL 模式打开：
   - `reader.openByUrl(bookId, url)`
   - 如果本地已下载，优先使用本地 blob；否则使用远程 URL。
3. 书籍 URL 统一使用相对路径 `/books/{id}.epub`，部署到任何域名自动适配。
4. 失败降级：如果远程加载失败，提示用户下载离线版本。

#### 涉及文件
- `public/school-library.js`：按钮状态、下载逻辑。
- `public/school-reader.js`：新增 `openByUrl`、本地/远程切换。
- `public/school-app.js`：渲染两个按钮、事件分发。
- `public/index.html`、`index.html`、`docs/index.html`：同步 UI 与事件绑定。

### 2.3 【我的】页面视觉重设计

#### 设计原则
- 保持项目整体风格：宣纸白底、墨色文字、暗金点缀、楷体优先、方正黑框、无圆角无阴影。
- 增加信息层级和品牌氛围，但不花哨。

#### 页面结构

```
┌─────────────────────────────────────┐
│  顶部用户信息卡片（暗金纹理背景）      │
│  [头像]  用户_905              [⚙️]  │
│          ID: 6350_905               │
└─────────────────────────────────────┘
┌──────────────┬──────────────────────┐
│  排盘 12     │  收藏 3              │
│  学习 5 天   │  会员 未开通         │
└──────────────┴──────────────────────┘
┌─────────────────────────────────────┐
│  快捷入口（2×2 宫格）                 │
│  [我的收藏] [我的消息] [阅读历史] [简繁转换] │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│  工具箱                             │
│  四柱八字 · 紫微斗数 · 梅花易数 · 大六壬 │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│  系统                               │
│  基础设置 · 夜间模式 · 关于         │
└─────────────────────────────────────┘
```

#### 样式要点
- 顶部卡片：`background: linear-gradient(135deg, #f5f0e8 0%, #e8e0d0 100%)`，底部 1.5px 墨色边框，暗金纹理 SVG 背景。
- 数据卡片：双列 flex，数字用暗金色 `#b8954a`，标签用墨色辅助色。
- 宫格入口：2×2 网格，图标 + 文字，点击区域 44×44dp 以上。
- 分组列表：分组标题小字加粗、灰色，组内项 1px 浅灰下分隔线。

#### 涉及文件
- `public/index.html`：重写 `#page-profile` 结构。
- `index.html`、`docs/index.html`：同步结构。
- `public/user-pages.js` 或内联 `<script>`：数据绑定（排盘次数、收藏数等）。

- `qimen_history_<userId>`：已用于历史记录，可统计排盘次数。

## 六、风险与回退

| 风险 | 应对措施 |
|------|----------|
| Render 免费实例休眠导致首次访问慢 | 这是 Render 免费套餐固有限制，可接受；如不满意后续可升级 |
| EPUB 文件较大，在线加载慢 | 书籍均在 200KB 以内，影响很小 |
| 我的页面数据为空时难看 | 空数据时显示 "0" 或 "暂无"，不隐藏卡片 |
| GitHub 推送失败 | 如 443 端口抖动，按之前经验手动重试 |
