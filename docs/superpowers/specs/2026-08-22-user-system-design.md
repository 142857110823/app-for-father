# 用户系统与管理后台设计文档

## 背景

将 `完善方向.txt` 中的后端功能落地为可见产品：
- 用户端 APP UI：登录/注册、个人资料、历史记录、会员中心、AI 对话记录
- 独立管理后台：用户管理、会员/订单、公告/消息、数据统计

## 范围

第一版实现范围（方案 A）：
1. 先做用户端 APP UI，再做独立管理后台
2. 认证方式：账号密码 + 模拟短信验证码（固定码：629805）
3. 复用现有 `backend/` API，按需补充字段和分页
4. 保持现有视觉风格：宣纸白/墨色/暗金，楷体优先

## 用户端 APP 设计

### 导航结构

底部 4 标签导航：
- **首页**：现有起局输入 + 排盘结果
- **历史**：排盘历史列表
- **会员**：套餐与额度
- **我的**：个人资料、AI 记录、消息、登录/登出

### 页面与组件

#### 1. 登录/注册弹窗

- 字段：手机号、密码
- 切换：账号密码登录 / 短信验证码登录
- 短信验证码：固定输入 `629805` 即可通过
- 按钮：登录、注册
- 登录成功后：保存 token，关闭弹窗，刷新“我的”页

#### 2. 我的

- 未登录：显示头像占位 + “登录/注册” 入口
- 已登录：
  - 头像 + 昵称 + 会员等级
  - 功能入口：个人资料、历史记录、AI 对话、消息中心、会员中心、设置/登出

#### 3. 个人资料页

- 昵称（文本）
- 头像（默认占位，支持上传 base64/URL）
- 性别（男/女/保密）
- 出生年月日时（日期 + 时辰选择）
- 常住地 / 出生地（文本）
- 保存按钮

#### 4. 历史记录页

- 顶部搜索框（按标题/四柱搜索）
- 列表项：时间、标题、四柱、遁局、收藏星标
- 操作：点击查看详情、收藏切换、删除
- 排序：时间倒序，收藏置顶

#### 5. 会员中心页

- 当前会员状态卡片（等级、有效期、剩余 AI 次数）
- 套餐列表：月卡 / 年卡 / 永久
- 每个套餐：名称、价格、权益、购买按钮
- 购买：模拟支付，调用 `/api/payment/create-order` + `/api/payment/simulate-pay`

#### 6. AI 对话记录页

- 会话列表：时间、问题摘要、关联排盘标题
- 点击：查看完整对话（只读）

### 数据流

```
APP UI → fetch → backend API → SQLite → response → UI update
```

Token 存储：`localStorage.token`

### 错误处理

- 网络错误：Toast 提示“网络异常，请重试”
- 业务错误：使用后端返回的 `msg`
- 未登录访问需登录页：自动弹出登录框

## 管理后台设计

### 页面结构

独立单页 `public/admin.html`：

1. **登录页**：管理员账号 + 密码
2. **概览页**：用户总数、今日新增、排盘总数、今日排盘、收入统计
3. **用户管理**：
   - 用户列表：ID、手机号、昵称、会员等级、注册时间
   - 搜索：手机号/昵称
   - 操作：查看详情、禁用/启用
4. **会员/订单**：
   - 订单列表：订单号、用户、套餐、金额、状态、时间
   - 手动开通会员按钮
5. **公告/消息**：
   - 公告列表：标题、内容、发布时间
   - 新建公告表单
   - 消息列表：用户消息
6. **数据统计**：
   - 最近 7 天新增用户折线图
   - 最近 7 天排盘次数折线图

### 管理员认证

- 固定管理员账号：`admin` / `admin123`（或从数据库初始化）
- 登录后返回 admin token，存储 `localStorage.adminToken`
- 访问后台页自动校验 token

## 后端调整

1. **auth.js**：
   - 短信验证码固定校验 `629805`
   - 注册/登录返回统一格式 `{ok, msg, data: {token, user}}`

2. **user.js**：
   - `GET /api/user/profile` 返回完整资料
   - `PUT /api/user/profile` 支持全部字段

3. **history.js**：
   - 列表支持 `keyword`、`is_favorite`、`page`、`size`
   - 返回关联的用户信息

4. **payment.js**：
   - 套餐接口返回价格/权益
   - 模拟支付直接开通会员并增加 AI 额度

5. **notification.js**：
   - 公告列表支持分页
   - 消息支持按用户读取

6. **admin.js**：
   - 增加管理员登录
   - 增加用户列表、禁用/启用
   - 增加订单列表、手动开通会员
   - 增加统计接口（用户数、排盘数、收入）

## UI 核对流程

每完成一个页面后：
1. 本地启动 `node server.js`
2. 浏览器打开 `http://localhost:8080`
3. 逐项检查：布局、间距、字号、颜色、对齐、交互反馈
4. 发现任何问题立即修复
5. 用户确认无问题后进入下一页

## 成功标准

- 用户端：登录/注册、资料、历史、会员、AI 记录功能可用且 UI 无可见问题
- 管理端：管理员可登录并管理用户、订单、公告、查看统计
- 所有实现与现有排盘视觉风格一致
