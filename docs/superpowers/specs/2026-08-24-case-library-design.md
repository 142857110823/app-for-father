## 一、设计目标

当前奇门遁甲排盘算法已实现，但仅有 2 个测试用例（阳遁5局 + 阴遁5局），无法评估算法在更多遁局组合和时间条件下的准确性。

**核心需求**：
1. **算法回归测试**：批量生成 ~10,000 条排盘案例，作为回归基线，防止未来重构时改坏
2. **实际准确率验证**：通过人工排盘对照 + 实际问事结果跟踪，评估排盘和预测的实际准确率

**数据来源策略**：混合方案
- 少量人工验证案例（独立于算法，确认算法正确性）
- 大量算法自动生成案例（随机采样，做回归基线）

## 三、案例生成与使用流程

### 自动生成流程（~10,000条）

```
随机日期时间（2020-01-01 至 2030-12-31）
  → getFourPillars() 计算四柱干支
  → 农历月日 + 时支 + 昼夜判定
  → 贵神推算
  → fullPaiPan() 排盘
  → 写入 Sheet1 (A-Q列) + Sheet2 (13行/案例)
  → Sheet3 留空（待人工填充）
```

- 时间范围：2020-01-01 至 2030-12-31，覆盖十年，随机采样 10,000 个时间点
- 每个时间点精确到时辰（2小时一个时段），保证四柱有效
- 生成脚本输出 `案例库.xlsx`，放在项目 `algorithm/` 目录下

### 人工验证流程

```
拿到人工排盘结果或实际问事案例
  → 在 Sheet1 找到对应遁局组合的案例（或新增案例）
  → 填充 Sheet1 R-X列 + Sheet3 全部列
  → 与算法结果比对，记录差异
```

### 回归测试流程

```
读取 案例库.xlsx Sheet2
  → 逐案例调用 fullPaiPan()
  → 与 Sheet2 中存储的13宫×14字段比对
  → 输出差异报告
```
