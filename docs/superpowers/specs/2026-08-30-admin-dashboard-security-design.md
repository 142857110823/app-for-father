# 管理员后台与十三宫文案调整设计

## 1. 目标

1. 排盘结果的基础信息删除“公历”和“时辰”，保留农历、节气、姓名、性别和地点。
2. 宫位详情中的“八神、九星、八门”改为“十三神、十三星、十三门”，实际神、星、门数据不删除。
3. 完善管理员仪表盘，使其能反映用户、排盘、遁法、会员、订单和系统运行状态。
4. 管理员后台采用“访问密钥 + 管理员账号密码”两步登录，任何凭据均不得出现在前端源码或 Git。

## 2. 管理员认证

- 管理入口保持 `/admin`。
- 登录弹窗依次要求：访问密钥、管理员账号、管理员密码。
- 后端从 `admin-credentials.local.json` 或环境变量读取凭据。
- 本地凭据文件加入 `.gitignore`，只保存密码哈希、密钥哈希和随机 JWT 密钥。
- 登录成功后返回带 `role=admin`、`jti`、过期时间的 JWT。
- 所有 `/api/admin/*` 管理接口只校验管理员 JWT，不再复用普通用户 `tokens` 表。
- 连续登录失败按 IP 进行窗口限流；成功登录后清空失败计数。
- 前端令牌保存在 `sessionStorage`，关闭标签页后失效。
- 登录页不显示默认账号、密码或密钥。

## 3. 仪表盘

保留现有管理模块，并将总览补充为：

- 用户：总数、今日新增、近 7 日活跃。
- 排盘：总数、今日数量、阳遁数量、阴遁数量。
- 会员：有效会员、7 日内即将到期。
- 订单：待支付、已支付、累计收入。
- 趋势：近 7 日排盘数量。
- 最近活动：最近排盘、最近订单。
- 系统：运行时间、数据库可用状态、服务时间。

统计接口返回单一 `stats` 对象，前端只负责展示，不自行推算业务数据。

## 4. 页面与导出

- `public/index.html`、根目录 `index.html`、`docs/index.html` 保持一致。
- 宫位详情的分类名称统一为“十三神、十三星、十三门”。
- PDF/打印导出的基础信息同步删除“公历”和“时辰”。
- 管理后台只部署在本地 Node 服务；GitHub Pages 静态环境无法使用后端认证。

## 5. 验收

- 排盘结果基础信息不出现“公历”和“时辰”。
- 宫位详情不出现“八神、九星、八门”，改为“十三神、十三星、十三门”。
- 未输入完整三项凭据无法登录。
- 错误凭据返回统一错误，不暴露具体错误项。
- 管理接口拒绝普通用户 JWT、伪造令牌和过期令牌。
- 仪表盘所有统计字段可正常加载，空数据库时显示 0 或空列表。
- 桌面和窄屏页面无重叠、截断或横向溢出。
