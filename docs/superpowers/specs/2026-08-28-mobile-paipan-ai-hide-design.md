# 手机端排盘修复设计文档

## 背景
用户在手机端发现三个问题：
1. 【智能解读】在 GitHub Pages 静态部署下显示“暂不可用”长文本，视觉体验差。
2. 【排盘结果】手机端未严格按「左：神/星/门」「中：灵/天/人/地」「右：天罡/月局/节气/日局」三列呈现。
3. 字号固定，导致窄屏下文字重叠或显示不全。

## 设计目标
- 静态环境下直接隐藏【智能解读】入口，避免展示不可用提示。
- 手机端宫位恢复严格左/中/右三列布局，右列标签竖排或合理换行。
- 提供字号调节能力，确保不同宽度手机都能完整显示、不重叠。

## 方案

### 1. 智能解读隐藏策略
- 页面加载及每次排盘后，检测当前是否为静态部署：
  - `location.hostname` 以 `github.io` 结尾；或
  - 通过轻量 fetch 探测 `/api/chat`/`/api/health`，若返回 HTML 或网络错误。
- 若判定为静态环境，将 `#ai-interpret` 设为 `display:none`，不渲染面板。
- 本地 `localhost:8090` 启动 Express 服务后，面板正常显示。

### 2. 手机端宫位三列布局
- 修改 `@media (max-width:540px)`：
  - `.palace-tri` 保持 `flex-direction:row`，取消上下堆叠。
  - 左列 `.palace-col-left` 占内容宽度，放置神/星/门。
  - 中列 `.palace-col-mid` 占内容宽度，放置灵/天/人/地。
  - 右列 `.palace-col-right` 固定宽度 28–32px，flex-shrink:0，竖向排列天罡/月局/节气/日局。
  - 天罡标签 `.pc-tg` 与节气 `.pc-jq` 保持 `writing-mode:vertical-rl` 竖排；月局、日局小字号右对齐。
  - 所有列设置 `min-width:0`、`overflow-wrap:anywhere`，防止溢出重叠。
- 中宫保持现有左右分区，不受影响。

### 3. 字号调节
- 在「排盘结果」工具栏增加 `A- / A+` 字号切换按钮。
- 提供小/默认/大三档，通过切换 `#plate-table` 的 class（如 `plate-fs-sm`、`plate-fs-md`、`plate-fs-lg`）实现。
- 默认档位在手机端使用足够小的字号，保证 375px 宽度下不重叠。
- 用户放大字号后，若屏幕宽度不足，右列可进一步压缩或自动换行，但左/中/右三列结构不变。

## 测试标准
- 375px、390px、414px 三个手机视口下，13 个外围宫均无文字重叠、无截断。
- 中宫 2×2 布局保持正常。
- GitHub Pages 部署后【智能解读】面板不可见；本地服务启动后可见。
- 字号按钮能实时切换，且各档位均无重叠。
